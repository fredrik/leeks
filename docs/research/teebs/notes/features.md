# Features

> Converted to markdown from `features.txt` (teebs@b817be9); the verbatim original is in git history.

- There should be "one true way". The tool is opinionated. However, alternative paths are possible.
- Adding to library, matching with sources, selecting best / right match, tag-writing, file naming, etc are separate
  activities.
- Artist is a top-level concept.
- Album is the main type.
- Editions, releases, etc are supported.
- I want batching! Add 50 albums to a queue, have the tool slowly match against MusicBrainz. Auto-add or HITL.
- I want genres, styles, moods. Discogs has this in spades.
- I want mixing of sources.
- I want regular updating of sources. Surely the trend in MusicBrainz etc is towards higher quality over time? So the
  library manager should keep polling for changes and update metadata.
- All plugins share the same basic options (`--dry-run`, etc).
- Source files are copied into the library and never modified.
- Source files are always accepted.
