# features

There should be "one true way". The tool is opinionated. However, alternative paths are possible.
Adding to library, matching with sources, selecting best / right match, tag-writing, file naming, etc are separate activities.
Artist is a top-level concept.
Album is the main type.
Editions, releases, etc are supported.
I want batching! add 50 albums to a queue, have beets slowly match against musicbrainz. auto-add or HITL.
I want genres, styles, moods. discogs has this in spades.
I want mixing of sources.
I want regular updating of sources. Surely the trend in musicbrainz etc is towards higher quality over time? so the library manager should keep polling for changes and update metadata.
All plugins share the same basic options (--dry-run, etc).
Source files are copied into the library and never modified.
Source files are always accepted.
