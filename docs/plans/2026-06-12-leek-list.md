# Slice 2, first half: `leek list`

Slice 2 is visibility — `list` and `info` (roadmap). The two verbs land on two branches; this plan covers `leek list`,
and `info` gets its own just-in-time plan when it starts. The design is pinned in
[ADR 0011](../decisions/0011-list-is-albums-in-shelf-order.md): albums only, shelf order, bare query terms.

## Verification

New behaviour, new tests, before the behaviour:

- `tests/test_list.py` — the query layer (`library.list_albums`):
  - an empty library lists nothing;
  - the full corpus comes back in shelf order: Polder Arcade, then Tin Hatch Choir 2019 before 2022, then Vesna
    Holloway;
  - within one artist, a missing year shelves after dated albums;
  - terms AND together, match case-insensitively, and reach artist, title, and year;
  - LIKE metacharacters in a term are literal (`%` matches nothing, not everything);
  - an album with no artist claim comes back with `artist=None`, sorts in the Unknown Artist bucket, and is *not* found
    by the term `unknown` — terms match data, not display fallbacks.
- `tests/test_cli_list.py` — the surface:
  - the shelf prints with artist, year, title, and track count, in shelf order;
  - terms narrow the listing;
  - an empty library points at `leek add`; an empty match says so; both exit 0 with a clean stdout;
  - one track is "1 track"; an artistless album shows Unknown Artist;
  - `list` appears in `leek help`.
- `just check` green at every commit; dogfood against a materialised scratch library through the installed `leek`.

## Build

1. **The query** — `library.list_albums(terms) -> list[Listed]`: one SQL statement over the merged view (albums ⟕
   artists ⨝ tracks, grouped per album), terms applied as ANDed case-insensitive LIKE filters with autoescape, shelf
   order in the ORDER BY (`coalesce(artist, 'Unknown Artist')` NOCASE, year with NULLs last, title NOCASE). `Listed` is
   a frozen dataclass like `Added`: id, artist, year, title, track count.
2. **The verb** — `leek list` in the CLI: lazy import, terms as a variadic argument, a borderless rich table (artist /
   year / title / count) themed like the rest of leeks. Unknown Artist renders dim italic — visibly a fallback, not
   data. Empty-library and no-match notes go to stderr so stdout stays a clean list of albums.
3. **Docs** — verbs.md status flip, glossary gains *shelf order* and *term*, this plan archives, journal entry.

## Punts

- **Query growth** (field-qualified terms, comparisons, per-track search): bare substring terms only, ANDed, until a
  real query demands more. Recorded in ADR 0011.
- **Track listing**: no per-track output from `list`; `leek info` shows one entity in depth, and a flat track view waits
  for a need.
